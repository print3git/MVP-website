# CI status

GitHub Actions attaches build outputs and caches to every workflow run so you can debug failures and download built assets.

## Artifacts
Artifacts generated by a job appear in the **Artifacts** section of its run page. Select the workflow run in the *Actions* tab, then download the zip files from the bottom of the page.

## Caches
Job logs show whether caches were hit or saved. You can also inspect caches from the **Caches** tab in a workflow run. The repository uses `actions/setup-node` and other cache-enabled steps, which store dependencies like `~/.npm` between runs.

## Skipping heavy jobs
Apply the `skip-ci` label to a pull request to omit costly jobs such as full end-to-end tests or large matrix builds. Remove the label when you need the full pipeline.
